# chanote v0.5.0 — スマートフォン対応 / Phones

*(English below)*

## 日本語

chanote が iPhone / iPad と Android で動くようになりました。画面は縦長レイアウト(下にタブ)に切り替わり、
記録・絞り込み・統計はパソコン版と同じです。

**Android**: このページの `chanote_0.5.0_android.apk` をインストールしてください
(「提供元不明のアプリ」を許可する必要があります)。

**iPhone / iPad**: iOS 版は作者が自分の端末で試している段階で、まだ配布していません。
Apple は App Store 経由でしか配布を認めていないため、ご要望が多ければ App Store での公開を検討します。
Xcode の入った Mac をお持ちの方は、ご自身の端末に入れられます(CONTRIBUTING.md)。

**データの出し入れ**: スマートフォンでは書き出し(JSON / CSV)とバックアップ zip を、iOS では「ファイル」アプリの
「このiPhone内 → chanote」、Android では保存ダイアログで選んだ場所に保存します。パソコンに移して
「設定 → JSON を読み込む」で取り込めます(重複は自動で検出)。端末間の**自動同期は次のバージョン (v0.5.1)** で、
iCloud Drive / Dropbox などのフォルダを介した方式で対応する予定です。

そのほか:
- 裏千家パックに **灰形** を追加(炭手前の分類)。
- バックアップからの復元が、再起動なしでその場で反映されるようになりました。
- 既知の制限: iOS で HEIC の写真を添付すると、原本は保存されますがサムネイルは表示されません(次版で対応)。

アップデート: データベースの変更はありません。v0.4 からそのまま開けます。

## English

chanote now runs on iPhone / iPad and Android. Below 768 px the layout switches to a single
column with bottom tabs; records, filters and statistics are the same as on the desktop.

**Android**: install `chanote_0.5.0_android.apk` from this page (you will be asked to allow
installs from unknown sources).

**iPhone / iPad**: the iOS build is being tried out on the author's own device and is not
distributed yet — Apple only allows distribution through the App Store, which will be
considered if there is enough interest. If you have a Mac with Xcode you can install it on
your own device (see CONTRIBUTING.md).

**Getting data in and out**: on a phone, exports (JSON / CSV) and backup zips are written to
the Files app (On My iPhone → chanote) on iOS, or to a location you choose in the Android save
dialog. Move them to your computer and use *Settings → Import JSON* (duplicates are detected).
**Automatic sync between devices comes in the next version (v0.5.1)**, through a folder in
iCloud Drive / Dropbox or similar.

Also:
- Urasenke pack: **灰形 (haigata)** added under charcoal procedures.
- Restoring a backup now takes effect in place, without restarting the app.
- Known limitation: HEIC photos attached on iOS are stored but show no thumbnail yet (next release).

Upgrading: no database changes; v0.4 data opens as is.
