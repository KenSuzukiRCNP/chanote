# chanote v0.5.1 — 端末間の同期 / Sync between devices

*(English below)*

## 日本語

Mac と iPhone(や別の Mac / Windows)で同じ日記を使えるようになりました。

**使い方**: 設定 → 「同期」 → 「同期フォルダを選ぶ」で、iCloud Drive や Dropbox の中のフォルダを選びます。
最初の1台で「新しい日記を作る」、ほかの端末では同じフォルダを選んで「この日記に参加」。
あとは起動時・保存の数秒後・3分ごと・アプリに戻ったときに自動で同期します。

**しくみ**: データベース本体は各端末に置いたままで、各端末が自分の変更だけを記録したファイルを
そのフォルダに追記します。同じファイルを2台が書き換えることがないので、クラウドの同期と衝突しません。
アカウントやサーバーは不要で、データはあなたのクラウドフォルダの外に出ません。

- 参加する端末に既にある記録(JSON で移したものなど)は、日付・場所・点前が同じなら同じ記録として扱い、二重になりません。
- 2台で同じ記録をほぼ同時に変えた場合は新しいほうを残し、もう一方を「競合」として残します。「こちらに戻す」で復元できます。
- iPhone / iPad では iCloud Drive 内のフォルダを選んでください。
- Android はまだ同期に対応していません(JSON の書き出し/読み込みは使えます)。

そのほか:
- iPhone で HEIC の写真にもサムネイルが付くようになりました(取り込み時に JPEG へ変換)。
- iOS / Android のアプリアイコン。

**アップデートの前に**: データベースは初回起動時に自動で更新されます(マイグレーション 005)。
念のため 設定 → 「バックアップを保存」をしておくと安心です。バックアップから復元した端末は同期設定が解除されるので、
もう一度「この日記に参加」を選んでください。

iOS 版は引き続き作者の端末で試している段階で、App Store での配布はご要望があれば検討します。

## English

You can now keep one diary on your Mac and your iPhone (or another Mac / PC).

**How**: Settings → *Sync* → *Choose sync folder*, and pick a folder in iCloud Drive or Dropbox.
On the first device choose *Create new diary*; on the others pick the same folder and *Join
this diary*. From then on chanote syncs at start, a few seconds after you save, every three
minutes and when you return to the app.

**How it works**: each device keeps its own database and appends only its own changes, as
files, to that folder. No two devices ever write the same file, so the cloud service never
has to merge anything. There is no account and no server; your data stays in your own cloud
folder.

- Records already on a joining device (for example moved earlier by JSON export) are matched
  by date, place and procedures, so nothing is doubled.
- If two devices change the same record at about the same time, the newer change is kept and
  the other is listed under *Conflicts*, where you can bring it back.
- On iPhone / iPad, choose a folder in iCloud Drive.
- Android cannot sync yet (JSON export / import still works).

Also: HEIC photos taken on iPhone now get thumbnails (converted to JPEG on import), and the
iOS / Android apps have their icon.

**Before updating**: the database is upgraded on first start (migration 005); a backup
(Settings → *Save backup*) is a good idea. A device restored from a backup leaves sync; join
the diary again afterwards.

The iOS app is still being tried out on the author's device; App Store distribution will be
considered if there is interest.
